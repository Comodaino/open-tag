# open-tag — Flutter starter

A starting point for a Flutter app targeting **desktop, web, and Android**,
matching the provided design (title bar, deep-purple image placeholder,
floating action bar, light/dark theme toggle).

## What's included

```
lib/
  main.dart                     # App entry point, holds ThemeMode state
  theme/
    app_theme.dart              # All colors/typography — edit here to restyle
  screens/
    home_screen.dart            # Responsive layout: switches on orientation
  widgets/
    image_placeholder.dart      # Deep-purple tap target -> camera/gallery picker
    floating_action_bar.dart    # Sidebar (landscape) / grid (portrait) bar
pubspec.yaml
```

- **Portrait mode**: title bar on top, square image placeholder centered,
  a 2x2 grid action bar pinned to the bottom.
- **Landscape mode**: a vertical action bar/sidebar on the left, title bar
  and centered image placeholder on the right.
- **Image placeholder**: tapping it opens a bottom sheet with "Take a
  photo" / "Choose from gallery", backed by the `image_picker` package.
- **Theme**: `lib/theme/app_theme.dart` defines the light and dark
  `ThemeData`. The icon button in the title bar (sun/moon) toggles
  `ThemeMode` at runtime — no restart needed.
- **Action bar buttons**: currently placeholders that just show a snackbar
  with their label. Wire up real `onTap` callbacks in
  `home_screen.dart -> HomeScreen._items` when you're ready.

## Setting this up

This bundle only contains the `lib/` source and `pubspec.yaml` — it does
not include the generated native platform folders (`android/`, `web/`,
`linux/`, `macos/`, `windows/`), since those need to be generated by the
Flutter SDK itself. To get a runnable project:

1. Make sure the [Flutter SDK](https://flutter.dev) is installed, with
   desktop and web support enabled:
   ```bash
   flutter config --enable-macos-desktop --enable-windows-desktop --enable-linux-desktop
   ```
2. Create a fresh Flutter project in an empty folder:
   ```bash
   flutter create open_tag_app
   cd open_tag_app
   ```
3. Copy `lib/` and `pubspec.yaml` from this bundle into that project,
   overwriting the generated defaults.
4. Fetch packages:
   ```bash
   flutter pub get
   ```
5. Run it:
   ```bash
   flutter run -d chrome     # web
   flutter run -d macos      # or windows/linux
   flutter run -d <android-device-or-emulator-id>
   ```

## Android permissions

`image_picker` needs camera/storage permissions on Android. After running
`flutter create .`, open `android/app/src/main/AndroidManifest.xml` and
add (above the `<application>` tag):

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
```

If you support older Android versions, also add:

```xml
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />
```

## Notes / next steps

- The four action-bar buttons are placeholders (`Action 1`–`Action 4`).
  Give them real icons/labels/`onTap` handlers in `home_screen.dart`.
- Camera capture is hidden on web (`kIsWeb`) since browsers handle camera
  access differently — gallery/file picking still works there.
- Desktop camera capture via `image_picker` is limited; if you need native
  camera capture on desktop, you'll want a platform-specific package.
- App title text ("open-tag") lives in `_TitleBar` in `home_screen.dart`.
